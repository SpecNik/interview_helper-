# Рядом — помощник на интервью

Локальное приложение для Google Meet: распознаёт речь из выбранной вкладки Chrome и предлагает короткий ответ через DeepSeek с опорой на ваше резюме и вакансию.

## Запуск

Требуется **Node.js 24+** и **Chrome 135+ на компьютере**. Устанавливать npm-пакеты не нужно.

```sh
git clone https://github.com/SpecNik/interview_helper-.git
cd interview_helper-
node server.mjs
```

На Windows можно открыть `start.cmd`. Он использует Node.js из среды Codex, если она установлена, или команду `node` из PATH.

Откройте **http://127.0.0.1:8766/** в обычном Chrome. Оставьте сервер работающим; Ctrl+C останавливает его. При занятом порте задайте `PORT`, например в PowerShell: `$env:PORT='8767'`, затем `node server.mjs`.

## Использование

1. Нажмите **Подключение**, введите API-ключ DeepSeek и выберите **Использовать ключ**.
2. Вставьте резюме, описание вакансии и должность. Выберите язык ответа.
3. Проверьте ручной вопрос, например «Расскажите о себе», кнопкой **Предложить ответ** или Ctrl+Enter.
4. Откройте Google Meet в другой вкладке того же Chrome.
5. Нажмите **Начать слушать**, выберите вкладку Meet и включите **Поделиться аудио вкладки**. Выбор окна без аудиодорожки не подходит.
6. Выберите язык собеседника до начала прослушивания. После паузы в распознанной речи приложение автоматически запрашивает ответ. Для ручного управления снимите **Ответ после паузы**.
7. **Остановить** прекращает захват, **Отменить ответ** прекращает генерацию. Историю можно скачать в текстовый файл.

Ответ появляется по мере генерации. История позволяет вернуться к предыдущему вопросу. Модель получает указание не придумывать личный опыт и отмечать места, где нужен ваш реальный пример.

## Данные и API

- API-ключ хранится только в памяти вкладки и передаётся локальному серверу для обращения к `https://api.deepseek.com/chat/completions`. После обновления страницы его нужно ввести снова.
- Используется `deepseek-flash` без режима размышлений. Запросы расходуют баланс вашего аккаунта DeepSeek.
- Распознавание выполняет служба речи Chrome: аудио может передаваться сервису браузера. DeepSeek получает текст вопроса, резюме, должность и вакансию. Видео выбранной вкладки приложение не отправляет.
- Резюме и вакансия сохраняются в локальном хранилище браузера. История живёт в памяти до обновления страницы; скачайте её при необходимости.
- Сервер слушает только `127.0.0.1`, проверяет источник запросов и ограничивает размер ввода. Ключи и содержимое интервью не записываются в логи.

## Ограничения и проверка перед интервью

Распознавание аудиодорожки — экспериментальная возможность Chrome. Во встроенном браузере, при отсутствии сети или блокировке службы речи оно может не работать. Приложение захватывает звук удалённых участников из вкладки Meet; отдельного захвата вашего микрофона нет.

Пауза в речи не гарантирует конец вопроса: при длинном вопросе может появиться преждевременная подсказка. В этом случае выключите автоматический ответ и нажимайте кнопку после полного вопроса.

Код проверен автоматическими тестами с имитацией DeepSeek. Реальный звонок Meet и запрос с пользовательским API-ключом необходимо проверить коротким пробным звонком. При проблемах со звуком остаётся ручной ввод.

Используйте захват с согласия участников и согласно правилам интервью. Проверяйте предложенные ответы: модель может ошибаться.

## Проверки

```sh
node --test tests/*.test.mjs
```

Тесты проверяют валидацию, запрос к DeepSeek, потоковый ответ, обработку ошибок, разбиение UTF-8 при передаче и удаление ключа. Они не требуют API-ключа и не обращаются к внешним сервисам.

Документация: [DeepSeek API](https://api-docs.deepseek.com/), [SpeechRecognition.start(audioTrack)](https://developer.mozilla.org/en-US/docs/Web/API/SpeechRecognition/start).
